# Laravel Online Exam - Docker Setup

A Laravel-based Online Exam application running with Docker, Apache, PHP 8.3 and MySQL 8.

## Tech Stack

- Laravel
- PHP 8.3
- Apache
- MySQL 8.0
- Node.js 22
- Vite
- Docker
- Docker Compose
